<h1>Design Cart Sand Slider – Sand Particle Image Transitions for WordPress</h1>
<p>✨ <strong> Transform ordinary image sliders into captivating visual experiences. </strong></p>
<p>Design Cart Sand Slider is a WordPress plugin that brings a distinctive sand particle transition effect to image galleries and presentations. Instead of traditional fading or sliding animations, images gradually dissolve into thousands of tiny particles, revealing the next slide in a visually engaging way.</p>
<p>Powered by <strong> Three.js and WebGL </strong> , the plugin allows you to create animated image sliders without writing JavaScript or modifying your WordPress theme.</p>
<p>Whether you're building a creative portfolio, photography website, product showcase, or landing page, Sand Slider offers an alternative to conventional image carousels.</p>

<h2>🎨 What Makes Sand Slider Different?</h2>
<p>Most WordPress sliders rely on familiar transitions such as fading, horizontal movement, or zooming. While these effects are useful, they rarely become a memorable part of a website's visual identity.</p>
<p>Design Cart Sand Slider takes a different approach.</p>
<p>When a transition begins, the current image breaks apart into tiny particles that disperse across the screen, gradually exposing the next photograph.</p>
<p>The result resembles sand being scattered by the wind.</p>
<p>The effect can be adjusted to match different presentation styles, from dynamic product showcases to slower, atmospheric photography portfolios.</p>
<h2>⚙️ Configuration Options</h2>
<p>The plugin includes a dedicated WordPress administration interface for managing slides and controlling their appearance.</p>
<h3>Slide Content</h3>
<p>Each slide can include an image, heading, subheading, CTA button text, destination URL, and link target. Slides can be reordered using drag and drop.</p>
<h3>Layout &amp; Image Display</h3>
<p>Configure slider height, minimum height, background color, image fitting mode, and individual image frame margins.</p>
<h3>Particle Animation</h3>
<p>Fine-tune the visual effect through:</p>
<ul>
<li>
<p><strong> Hold Duration: </strong> Time each slide remains visible.</p>
</li>
<li>
<p><strong> Particle Grid Density: </strong> Controls the level of detail used to break the image into particles.</p>
</li>
<li>
<p><strong> Release Span: </strong> Adjusts the particle dispersion timing.</p>
</li>
<li>
<p><strong> Starting Slide: </strong> Defines the first image displayed.</p>
</li>
<li>
<p><strong> Underlay Dimming: </strong> Controls the darkness of the image revealed underneath.</p>
</li>
<li>
<p><strong> Dimming Fade Duration: </strong> Adjusts how quickly the dimming effect changes.</p>
</li>
</ul>
<h3>Playback &amp; Navigation</h3>
<p>Enable or disable autoplay, looping, navigation arrows, pagination dots, and underlying image dimming.</p>
<h3>Navigation Appearance</h3>
<p>Customize arrow colors, backgrounds, borders, hover states, pagination dots, and active indicators.</p>
<h2>🚀 Installation</h2>
<ol>
<li>
<p>Download the plugin ZIP package.</p>
</li>
<li>
<p>Open your WordPress administration dashboard.</p>
</li>
<li>
<p>Navigate to <strong> Plugins → Add New Plugin → Upload Plugin </strong> .</p>
</li>
<li>
<p>Select the ZIP package and install it.</p>
</li>
<li>
<p>Activate Design Cart Sand Slider.</p>
</li>
<li>
<p>Open the Sand Slider section in the WordPress dashboard.</p>
</li>
</ol>
<p>The plugin includes an example slider with five demonstration slides to help you explore the available animation settings.</p>
<h2>📌 Shortcode Usage</h2>
<p>Once your slider has been created, copy its shortcode and insert it into a WordPress page or post.</p>
<pre>  <code>
    [dc_sand_slider id="123"]
  </code>
</pre>
<p>Replace <code>
  123
</code> with your slider ID.</p>
<p>An alternative shortcode is also supported:</p>
<pre>  <code>
    [design-cart-sandslider id="123"]
  </code>
</pre>
<p>Each slider maintains its own slides, animation settings, and appearance configuration.</p>

<h2>⚡ Performance Considerations</h2>
<p>Sand Slider uses WebGL-based rendering through Three.js. Particle animation performance depends on the user's device, image dimensions, and configured particle density.</p>
<p>For the best experience, use appropriately optimized images, adjust grid density when necessary, and test your slider on desktop and mobile devices.</p>
